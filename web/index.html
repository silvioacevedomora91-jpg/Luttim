Acerca del proyecto

Ciencia rigurosa, experiencia inmersiva

ParasitoLab es un atlas educativo que combina visualización tridimensional en tiempo real con información clínica estructurada. Cada modelo se genera de forma procedural para representar la morfología característica del parásito —flagelos, escólex, pseudópodos o membranas ondulantes— de manera dinámica e interactiva.

  • 🔬 Modelos 3D animados con WebGL (Three.js)
  • 📚 Información clínica organizada por categorías
  • 🔄 Ciclos de vida paso a paso
  • 📱 Diseño responsivo para cualquier dispositivo

Nota educativa

El contenido tiene fines exclusivamente didácticos y de divulgación científica. No sustituye el juicio clínico ni el diagnóstico profesional. Las fuentes de referencia incluyen los CDC (DPDx), la OMS y manuales de parasitología médica.
